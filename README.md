# Medinova -- Responsive Hospital Website

A responsive hospital and healthcare website built with **HTML5, CSS3,
Bootstrap 5, JavaScript, and supporting frontend libraries**. This
project is designed as a modern medical website with multiple pages,
healthcare services, doctor profiles, appointment booking UI, medical
packages, testimonials, blog posts, and contact-related sections.

## 📌 Project Overview

**Medinova** is a hospital website template focused on presenting
healthcare information in a clean and responsive layout.

The homepage includes:

-   Responsive navigation bar
-   Hero section
-   About Us section
-   Medical services
-   Appointment booking form
-   Medical packages
-   Healthcare professionals / doctors
-   Doctor search section
-   Patient testimonials
-   Medical blog posts
-   Newsletter section
-   Footer with contact and social links
-   Back-to-top button

The project also contains separate pages for different sections of the
website.

## 🎨 Main Design Features

### Responsive Layout

The website uses Bootstrap's responsive grid system to adapt the layout
to different screen sizes, including desktop, tablet, and mobile
devices.

### Navigation

The navigation contains links for:

-   Home
-   About
-   Service
-   Pricing
-   Pages
-   Contact

The Pages menu contains links to the blog, team, testimonial,
appointment, and search pages.

### Hero Section

The hero section introduces Medinova with a healthcare-focused headline
and call-to-action buttons such as **Find Doctor** and **Appointment**.

### Medical Services

The homepage displays services including:

-   Emergency Care
-   Operation & Surgery
-   Outdoor Checkup
-   Ambulance Service
-   Medicine & Pharmacy
-   Blood Testing

### Appointment Form

The appointment section provides a form interface for:

-   Department selection
-   Doctor selection
-   Patient name
-   Email
-   Date
-   Time

### Medical Packages

The pricing section contains medical programs such as:

-   Pregnancy Care
-   Health Checkup
-   Dental Care
-   Operation & Surgery

### Doctors Section

The team section presents healthcare professionals with their
specialization and social media links.

### Testimonials

The testimonial section uses a carousel to display patient feedback.

### Blog

The blog section displays medical-related posts with images, author
information, views, and comments.

## ⚙️ Libraries

The project uses several frontend libraries:

-   **Bootstrap** -- Responsive layout and UI components
-   **jQuery** -- JavaScript utility library
-   **Owl Carousel** -- Carousel/slider functionality
-   **Tempus Dominus** -- Date and time picker
-   **Font Awesome** -- Medical and social icons
-   **Bootstrap Icons** -- Additional interface icons
-   **Waypoints** -- Scroll-based interactions
-   **Easing** -- Animation effects

## 🚀 How to Run

1.  Download or clone the project.
2.  Open the project folder in Visual Studio Code.
3.  Make sure the folder structure remains unchanged.
4.  Open `index.html` in your browser.

For a better development experience, you can use the **Live Server**
extension in Visual Studio Code.

## 🔗 Main Entry File

``` text
index.html
```

Open `index.html` to view the main Medinova homepage.
